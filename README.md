Laboratorio de Análisis de Datos y Consultas Avanzadas - SQL
Este repositorio contiene un conjunto de ejercicios, pruebas lógicas y ensayos de consultas relacionales utilizando SQL. El objetivo de este proyecto es demostrar la capacidad analítica para la extracción de información, la resolución de requerimientos de negocio y el manejo óptimo de estructuras de datos interconectadas.

Competencias Técnicas Demostradas

• Consultas Multi-tabla: Uso avanzado de sentencias INNER JOIN para unificar y correlacionar múltiples entidades lógicas del sistema (Vehículos, Sucursales, Inventarios).
• Filtros Dinámicos de Negocio: Aplicación precisa de cláusulas WHERE, operadores logados complejos (AND, OR) y exclusiones (!=) para segmentar datos según criterios específicos de la operación.
• Normalización y Relaciones: Comprensión práctica de llaves primarias y foráneas para la navegación eficiente entre tablas relacionales.

Casos de Negocio Resueltos en el Repositorio

El archivo de ensayos incluye la lógica SQL para responder a preguntas críticas de control de inventarios, tales como:
1. Auditoría de Inventario por Sucursal: Extracción e identificación de existencias y marcas específicas en locaciones determinadas de la empresa.
2. Filtrado Avanzado de Atributos: Consultas estructuradas para la exclusión de características específicas (ej. vehículos diferentes a color negro) y cruce con los datos de contacto de los responsables de venta para la toma de decisiones comerciales.
